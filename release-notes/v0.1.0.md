### Русский

- Первая версия WellSnap: выделите область, добавьте стрелки, рамки, маркер, размытие и пронумерованные сноски, затем скопируйте или сохраните.
- Несколько снимков собираются в набор и вставляются в чат одним альбомом, а вставка с текстом добавляет комментарии.
- Новые версии ставятся сами, пока вы не пользуетесь компьютером. Это можно выключить в разделе «О программе».

### English

- The first WellSnap release: select an area, add arrows, rectangles, highlighter, blur and numbered notes, then copy or save.
- Several screenshots form a set and paste into a chat as one album; paste with text adds the comments.
- New versions install themselves while you are not using the computer. You can turn this off under About.
