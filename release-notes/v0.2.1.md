### Русский

- macOS: WellSnap подписан и заверен Apple. Первый запуск больше не блокируется, и новые версии ставятся сами, как на Windows.
- macOS: после этого обновления система один раз попросит заново разрешить запись экрана и универсальный доступ. Дальше разрешения сохраняются между версиями.

### English

- macOS: WellSnap is now signed and notarized by Apple. The first launch is no longer blocked, and new versions install themselves, as on Windows.
- macOS: after this update the system asks once more for Screen Recording and Accessibility. From then on the permissions stay across versions.
