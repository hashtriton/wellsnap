### Русский

- Windows: после «Скопировать» можно сразу нажать Alt+Tab и перейти в нужную программу. Раньше уведомление «Скопировано» на пару секунд забирало клавиатуру, и первый Alt+Tab не срабатывал.
- То же для ленты набора: при добавлении снимка она больше не забирает клавиатуру.

### English

- Windows: right after Copy, Alt+Tab takes you straight to the app you need. The "Copied" notice used to take the keyboard for a couple of seconds, so the first Alt+Tab did nothing.
- The same for the set strip: adding a snapshot no longer takes the keyboard.
