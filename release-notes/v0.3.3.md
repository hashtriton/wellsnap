### Русский

- Новый раздел настроек «Обратная связь»: напишите автору прямо из программы. Адрес почты для ответа можно указать по желанию.
- Вместе с сообщением уходят только версия WellSnap, версия системы и язык интерфейса. Снимки и файлы не прикладываются.
- Кнопки «Написать автору» в разделах «О программе» и «Поддержка» открывают эту форму вместо страницы на GitHub.

### English

- New Feedback section in Settings: write to the author right from the app. An email address for the reply is optional.
- Only the WellSnap version, the system version and the UI language go with the message. No screenshots or files are attached.
- "Write to the author" under About and Support opens this form instead of a GitHub page.
