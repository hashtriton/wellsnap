### Русский

- На macOS исправлена потеря кадра при медленном открытии редактора после простоя.
- Запоздавший кадр отменённого захвата больше не заменяет новый снимок в редакторе.
- Исправлен цикл перерисовки, из-за которого панель инструментов могла исчезнуть при масштабе экрана 125%.
- В Windows исправлен случай, когда захват мог отмениться из-за медленного запуска редактора.
- В Windows исправлена потеря управления с клавиатуры при захвате на нескольких мониторах.

### English

- Fixed a lost frame on macOS when the editor takes longer to open after being idle.
- A late frame from a canceled capture no longer replaces the new screenshot in the editor.
- Fixed a rendering loop that could make the toolbar disappear at 125% display scaling.
- Fixed a case where a capture could be canceled if the Windows editor took longer to become ready.
- Fixed a case where keyboard shortcuts could stop working during a capture on multiple monitors in Windows.
